# text_stats

Утилита на Python 3 для подсчёта статистики текстового файла:
количество символов, слов, предложений и топ-5 самых частых слов.

## Назначение

Скрипт читает текстовый файл в кодировке UTF-8 и выводит:

- общее количество символов;
- количество слов;
- количество предложений;
- топ-N самых частых слов (по умолчанию N = 5).

## Требования

- Python 3.7+
- Только стандартная библиотека (никаких внешних зависимостей)

## Запуск

```bash
python3 text_stats.py <путь_к_файлу> [--top N]
```

Примеры:

```bash
python3 text_stats.py example.txt
python3 text_stats.py example.txt --top 10
python3 text_stats.py /home/user/docs/article.txt --top 3
```

## Пример входного файла (`example.txt`)

```text
Кот ест рыбу. Кот спит.
Пёс ест мясо.
```

## Пример вывода

```text
Символов: 40
Слов: 8
Предложений: 3
Топ-5 слов:
  кот: 2
  ест: 2
  рыбу: 1
  спит: 1
  пёс: 1
```

## Как считается «слово»

Слово — это непрерывная последовательность **букв** (Unicode: кириллица,
латиница и т.п.).

- Цифры в слово не входят.
- Знаки препинания, пробелы, переводы строк, подчёркивания — разделители,
  в слово не входят.
- При подсчёте топ-слов регистр приводится к нижнему, поэтому `Кот`, `кот`
  и `КОТ` считаются одним словом.
- При равной частоте порядок определяется порядком первого появления слова
  в тексте.

## Как считается «предложение»

Текст разбивается по символам `.`, `!`, `?`.

- Несколько подряд идущих разделителей считаются одним (`?!`, `...` и т.п.).
- Пустые фрагменты (пробелы, переводы строк между разделителями)
  не учитываются.

## Поведение при ошибках

При любой ошибке утилита печатает понятное сообщение в `stderr`
и завершается с кодом возврата `1`.

| Ситуация                     | Сообщение                                                 |
|------------------------------|-----------------------------------------------------------|
| Файл не найден               | `Ошибка: Файл не найден: <path>`                          |
| Путь указывает на папку      | `Ошибка: Указан путь к папке, а не к файлу: <path>`       |
| Нет прав на чтение           | `Ошибка: Нет прав на чтение файла: <path>`                |
| Файл не в кодировке UTF-8    | `Ошибка: Не удалось прочитать файл как UTF-8: <детали>`   |
| Файл пустой / только пробелы | `Ошибка: Файл пустой или содержит только пробелы: <path>` |

Пример:

```text
$ python3 text_stats.py nope.txt
Ошибка: Файл не найден: nope.txt
$ echo $?
1
```
